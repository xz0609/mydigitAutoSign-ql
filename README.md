# 数码之家自动签到 · 青龙面板使用说明

本项目脚本 `mydigit_AutoSign.py` 用于在青龙面板定时执行签到。

## 一、脚本机制

脚本采用 **用户名 + 密码** 的方式登录签到，每个账号独立执行：
`随机延迟 → 登录（取 loginhash/formhash）→ 签到 → 结果通知`

- 不做本地缓存，登录态不落盘，每次运行实时登录；
- 多账号通过 `ThreadPoolExecutor` 并发执行，各账号携带独立随机延迟，避免同时请求触发风控。

## 二、按订阅方式添加脚本到青龙

青龙可通过**订阅**一个远程 git 仓库自动拉取脚本，脚本内含 `new Env(...)` 与 `cron:` 头注释，青龙会据此自动生成脚本和定时任务，无需手动粘贴。

### 第 1 步：在青龙添加订阅

1. 打开青龙面板 → **订阅管理** → **新增订阅**；
2. 填写以下配置：
   - 名称：`数码之家`（随意）
   - 类型：公开仓库
   - 仓库地址：`https://wget.la/https://github.com/xz0609/mydigitAutoSign-ql.git`
   - 分支：`main`（按你的仓库实际分支填写）
   - 拉取目录：留空（拉取整个仓库），或填脚本所在子目录
3. 保存后点击该订阅的 **一键执行**（拉取）按钮；

### 第 2 步：生成定时任务

- 拉取完成后，脚本会同步到 `/ql/data/scripts/<仓库名>/mydigit_AutoSign.py`；
- 青龙会自动识别脚本头部的 `cron: 5 11 * * *` 生成定时任务（默认每天 11:05），无需手动新建脚本；
- 若要改签到时间，直接修改仓库中脚本头部那行 `cron:` 并重新拉取即可。

## 三、配置环境变量

在青龙面板 **环境变量** 中新增（变量名区分大小写）。

### 环境变量一览

| 变量名 | 必填/选填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `MYDIGIT_ACCOUNT` | **必填** | 无 | 账号列表，格式见下方示例 |
| `QUESTION_ID` | 选填 | `0` | 登录安全问题 ID，`0` 表示不使用 |
| `ANSWER` | 选填 | 空 | 登录安全问题答案 |
| `MAX_RANDOM_DELAY` | 选填 | `3600` | 每个账号随机延迟最大秒数（0~该值），设为 `0` 关闭随机延迟 |
| `PRIVACY_MODE` | 选填 | `true` | 隐私模式，控制台脱敏显示用户名 |

### `MYDIGIT_ACCOUNT` 格式

- 一行一个账号，**用户名 空格 密码**；
- 多个账号用换行分隔；
- 示例：

```
user1 pass1
user2 pass2
```

> 若账号登录需要安全问题：额外配置 `QUESTION_ID`（问题 ID）和 `ANSWER`（对应答案）。


### 安全提问 ID 对照表

| ID | 问题 |
|----|------|
| 0 | 未设置安全提问 |
| 1 | 母亲的名字 |
| 2 | 爷爷的名字 |
| 3 | 父亲出生的城市 |
| 4 | 您其中一位老师的名字 |
| 5 | 您个人计算机的型号 |
| 6 | 您最喜欢的餐馆名称 |
| 7 | 驾驶执照最后四位数字 |


## 四、配置定时任务

通过订阅仓库拉取的脚本，青龙会自动按脚本头部的 `cron: 5 11 * * *` 注释生成定时任务（默认每天 11:05），一般无需手动配置。

若需调整签到时间，直接修改仓库中脚本头部那行 `cron:` 并重新拉取订阅即可，例如改为：

```
cron: 0 8 * * *
```

若青龙未自动生成（需手动新增），可在 **定时任务** 中新增，填写 Cron 表达式（如 `5 11 * * *`），执行命令填 `task /scripts/<仓库名>/mydigit_AutoSign.py`。

## 五、配置通知

脚本会自动加载青龙面板的 `notify` 通知模块（需先按青龙部署流程配置好推送，如 企业微信/Server酱/Bark 等）。
若未加载到 `notify`，会把通知内容打印在运行日志中，不影响签到本身。

## 六、验证运行

1. 在 **定时任务** 中点击该任务的 **运行** 按钮，或手动命令执行；
2. 查看运行日志：显示账号数、是否成功签到、随机延迟情况；
3. 如提示 `未找到MYDIGIT_ACCOUNT环境变量`，说明环境变量未配置或名称不对；
4. 如提示 `用户名或密码错误`，检查账号行格式是否 `用户名 密码`，或安全问题配置是否正确。

## 七、注意事项

- 脚本不保存登录态，每次运行都会真实登录一次，请保证账号可用；
- 随机延迟默认最大 1 小时，如希望更早签完，可调小 `MAX_RANDOM_DELAY`；设为 `0` 可完全关闭随机延迟；
- 所有账号并行运行（不限制并发数），多个账号会在同一时间点触发，可能被站点风控；如遇问题建议调大 `MAX_RANDOM_DELAY` 拉大账号间的错峰延迟；
- 不要在 `MYDIGIT_ACCOUNT` 中夹带多余空格，否则可能解析失败。
